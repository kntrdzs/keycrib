Still can't find it?

Keyboard Viewer: System Settings → Keyboard → Text Input → Input Sources: Edit… → turn on “Show Input menu in menu bar”. Then choose “Show Keyboard Viewer” from the input menu. Hold Option to see what each key types.

Character Viewer: Control + Command + Space opens every character and emoji, searchable.
